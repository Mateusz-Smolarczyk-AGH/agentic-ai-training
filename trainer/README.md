# For the instructor

This directory is **for you only**. Nobody in the workshop points the agent at these paths, and
the exercise flow (docs/) deliberately does not refer to them.

## Rule

The mini-project bug list must **stay hidden from the agent** during the review — otherwise the
agent will read the answer instead of finding it on its own. Therefore:

- `trainer/` is not referenced from any workshop page (`docs/`),
- do not paste this path to participants or to the agent **before** the review produces its own
  report,
- only after comparing the agent's report with the list may you point out what is missing.
