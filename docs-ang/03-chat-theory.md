# Theory — what a chat is

In this block, first the chat theory, then the exercise. You will find the diagram and the figure on the trainer's slides.

## Basic concepts

| Term               | Meaning                                                                                  |
|--------------------|------------------------------------------------------------------------------------------|
| **LLM**            | large language model — it predicts the next tokens; on its own it does not "do" anything |
| **Token**          | a piece of text, the unit of the model's input/output                                    |
| **Prompt**         | what we send to the model                                                                |
| **System prompt**  | a fixed instruction that sets the model's behaviour                                      |
| **Context window** | how much text the model sees at once                                                     |
| **Hallucination**  | a confident-sounding but untrue answer                                                   |

## Done when…

- you can explain: LLM, token, prompt, system prompt, context window, hallucination,
- you know that the model checks nothing on its own.
