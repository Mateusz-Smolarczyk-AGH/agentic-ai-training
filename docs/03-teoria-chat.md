W tym bloku najpierw teoria czatu, potem ćwiczenie. Schemat i rysunek znajdziesz na slajdach prowadzącego.

## Podstawowe pojecia

| Pojęcie             | Znaczenie                                                                  |
|---------------------|----------------------------------------------------------------------------|
| **LLM**             | duży model językowy — przewiduje kolejne tokeny; sam z siebie nic nie „robi”   |
| **Token**           | kawałek tekstu, jednostka wejścia/wyjścia modelu                            |
| **Prompt**          | to, co wysyłamy do modelu                                                   |
| **Prompt systemowy**| stała instrukcja ustawiająca zachowanie modelu                              |
| **Okno kontekstu**  | ile tekstu model widzi naraz                                                |
| **Halucynacja**     | pewnie brzmiąca, nieprawdziwa odpowiedź                                     |

## Gotowe, gdy…

- umiesz wyjaśnić: LLM, token, prompt, prompt systemowy, okno kontekstu, halucynacja,
- wiesz, że model sam z siebie niczego nie sprawdza.
